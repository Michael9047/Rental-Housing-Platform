## 2. 通用约定

| 规则 | 说明 |
|------|------|
| 主键 | `id: int`，自增；部分表用 `id: UUID4`（payments, contracts, signatures） |
| 时间戳 | `TimestampMixin`：`created_at` (server_default=now()) + `updated_at` (onupdate=now()) |
| 软删除 | `unit_types.deleted_at`（仅户型表使用 DateTime soft-delete）；其余表无软删除 |
| 外键 | 命名 `{表}_{列}_fkey`；大部分业务表用 CASCADE 删除，签名/审计表用 RESTRICT |
| 金额 | `Numeric(12,2)` 用于租金/汇率；`int`/`BigInteger` 用于支付（以分为单位） |
| 比例 | `Float`（如折扣率、税率、评分） |
| 枚举 | Python Enum → 字符串存储，Pydantic 侧做 enum 校验 |
| JSON | `JSONB`，用于灵活字段（amenities, metadata, snapshot） |
| 向量 | pgvector `Vector(1536)`，仅 `unit_types.embedding` |
| 索引 | 外键列 + 高频查询列 + 复合索引（user_id + status + created_at 等） |

- 所有外键列自动建索引（部分 ORM 显式声明）
- pgvector: IVFFlat 索引 `lists = sqrt(row_count)`（建议定期 REINDEX）
- 复合索引用于高频组合查询（user_id + status + created_at 模式）

- `embedding_jobs.property_id` FK → `properties.id`，但 `properties` 表已删除。需迁移为 `unit_types.id`

## 5. 迁移管理

- **工具**：Alembic
- **命名规范**：`YYYYMMDD_NNNN_简述.py` 或简短 SHA
