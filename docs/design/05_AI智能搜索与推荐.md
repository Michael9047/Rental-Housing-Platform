## 1. 模块概述

### 1.1 定位

AI 智能搜索与推荐是平台的核心差异化模块，提供从"自然语言搜房 → AI 对话交互 → 多维度对比 → 最终推荐"的完整智能搜索链路。

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 自然语言解析 | 用户输入"离XX大学近、月租<5000、有独立卫浴"→ LLM 解析为结构化搜索条件 |
| AI 对话看房 | 多 Agent 对话（FAQ/搜索/筛选/对比/购物车），SSE 流式响应 |
| 向量语义搜索 | pgvector 嵌入向量 + 语义相似度检索 |
| 搜索建议/补全 | 学校名、地铁站、区域等自动补全 |
| 房源对比 | 多房源并排对比（价格/通勤/设施/安全评分） |
| 搜索漏斗 | 宽泛匹配 → 条件筛选 → 精准推荐 → 购物车留存 |

### 1.3 多 Agent 架构

```
用户消息
    │
    ▼
┌──────────────┐
│  Supervisor   │  路由决策：该谁处理？
└──────┬───────┘
       │
   ┌───┼───────────┬───────────┬──────────┐
   ▼   ▼           ▼           ▼          ▼
┌────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│FAQ │ │Search  │ │Filter  │ │Compare │ │Cart    │
│Agent│ │Agent  │ │Agent   │ │Agent   │ │Agent   │
└────┘ └───────┘ └────────┘ └────────┘ └────────┘
   │       │          │          │          │
   └───────┴──────────┴──────────┴──────────┘
                      │
                      ▼
              ┌──────────────┐
              │  Synthesizer │  汇总生成最终回复
              └──────────────┘
```

## 2. 核心流程

### 2.1 搜索漏斗

```
第1层 - 宽泛匹配 (Recall Pool ~120)
  │  向量语义搜索 + 地理半径 + 学校关联
  │
  ▼
第2层 - 条件筛选 (Filter → ~25)
  │  价格/户型/租期/设施/性别限制/通勤距离
  │
  ▼
第3层 - 精准推荐 (Score & Recommend → ~5)
  │  多维度打分：通勤/安全/配套/价格/库存
  │
  ▼
第4层 - 购物车 (Cart → 用户留存)
  │  用户手动收藏 + AI 自动推荐
  │
  ▼
第5层 - 对比 (Compare → 决策)
    并排对比 + 差异高亮 + 推荐理由
```

### 2.2 SSE 对话流程

```
前端 SearchAgentPanel / AgentView
  │
  │ POST /agent/sessions/{id}/messages/stream
  │ (Accept: text/event-stream)
  │
  ▼
后端 agent.py
  │
  ├── 1. 写入用户消息（ChatMessage role=user）
  ├── 2. 检索上下文（向量检索 + 用户记忆 + 会话状态）
  ├── 3. Supervisor 路由 → 分发到具体 Agent
  ├── 4. Agent 执行（LLM 调用 + Tool Loop）
  ├── 5. Synthesizer 汇总
  └── 6. SSE 逐 token 推送 → 结束时写入 AI 消息
```

## 7. 异常处理

| 场景 | HTTP 状态码 | 用户提示 |
|------|------------|----------|
| LLM 超时 | 504 | "AI 响应超时，请稍后重试" |
| LLM API key 无效 | 502 | "AI 服务暂时不可用" |
| Embedding 生成失败 | —（后台重试） | 不影响用户搜索（回退到关键词搜索） |
| 搜索结果为空 | 200 (空数组) | "未找到匹配房源，试试放宽条件" |
| SSE 连接中断 | — | 前端自动重连 + 显示"重新连接中" |
