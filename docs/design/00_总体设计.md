## 1. 项目概述

**项目名称**：Rental Housing Matching System（租房平台）

**项目定位**：为留学生/租客提供从搜索、预约、支付到签署留房确认协议的一站式租房服务平台。平台连接租客（Tenant）、楼栋管理员（Building Manager/BM）、系统管理员（Admin）和维修工人（Maintenance Worker）四类角色。

**核心价值**：
- 租客：AI 智能搜房 → 预约看房 → 支付留房手续费 → 获取合同
- BM：管理楼栋/户型/图片 → 处理预约 → 收取手续费
- Admin：全局管理用户/楼栋/数据导入导出
- 维修工：接收维修工单 → 更新维修状态

                              ┌──────────────────┼──────────────────┐

                         ┌────▼────┐      ┌─────▼─────┐     ┌─────▼─────┐
                         │PostgreSQL│      │   Redis    │     │  Celery   │

- **生产环境**：前端 `dist/` 由 Nginx 直接 serve，API 请求反向代理到 uvicorn

## 6. 全局约定

| 约定 | 说明 |
|------|------|
| API 版本 | `/api/v1/` 前缀，路由注册到 `app/api/v1/router.py` |
| 认证方式 | Bearer JWT（access_token 60min + refresh_token 7d） |
| 响应格式 | 成功返回数据体，错误返回 `{"error": {"type": "...", "message": "..."}}` |
| 金额类型 | 后端 `Decimal`，前端 `string`（避免浮点精度问题） |
| 时间格式 | ISO 8601 (UTC)，前端展示转本地时区 |
| 图片存储 | 本地 `uploads/` 目录，通过 `/api/v1/uploads/` 静态挂载 |
| 分页 | `skip` + `limit`，无 page 参数 |
| 异步 | 后端全链路 async，不写同步阻塞调用 |
