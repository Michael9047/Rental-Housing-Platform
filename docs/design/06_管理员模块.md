> 版本：v1.0 | 日期：2026-08-10 | 作者：[同学 C]

## 1. 模块概述

### 1.1 定位

管理员模块为系统管理员（Admin 角色）提供全局管控能力：用户管理、楼栋审核、运营数据看板、数据导入导出、审计日志查阅。

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 运营数据看板 | 注册用户数、房源数、订单数、支付金额等统计 |
| 用户管理 | 查看/编辑用户角色、禁用/启用用户 |
| 楼栋管理（全局） | 查看所有楼栋、审核上下架、回收站管理 |
| 数据导入导出 | Excel 批量导入楼栋/户型数据，导出错误报告 |
| 审计日志 | 全局操作记录查询（谁在什么时候做了什么） |
| 系统配置 | 平台参数配置（后续版本） |

---

## 2. 权限边界

```
Admin 角色：
  ✅ 查看/操作所有楼栋（不限于自己的）
  ✅ 查看/编辑所有用户
  ✅ 查看全局审计日志
  ✅ 数据导入导出
  ✅ 审核楼栋上下架
  ✅ 查看 BM/维修工状态
  ✅ 查看升级工单
  ❌ 不能代租客发起预约/支付
  ❌ 不能代 BM 签署合同
```

### 3.3 关键 Schema

> 文件 `backend/app/schemas/user.py`、`admin.py`、`notification.py`

**用户管理**（`user.py`）

| Schema 类 | 用途 | 关键字段 |
|-----------|------|----------|
| `UserBase` | 用户基类 | `username: str`, `phone: str\|None`, `wechat_openid: str\|None`, `email: EmailStr\|None`, `role: UserRole`, `status: UserStatus` |
| `UserCreate` | 创建用户 | 继承 UserBase + `password_hash: str\|None` |
| `UserUpdate` | 编辑用户 | 全部字段可选：`username`, `password_hash`, `phone`, `wechat_openid`, `email`, `role`, `status` |
| `UserProfileUpdate` | 个人更新 | `extra="forbid"`, `username: str\|None`, `phone: str\|None`, `email: EmailStr\|None` |
| `UserRead` | 用户响应 | 继承 UserBase + `id: int`, `created_at`, `updated_at` |

**认证**（`auth.py`）

| Schema 类 | 用途 | 关键字段 |
|-----------|------|----------|
| `RegisterRequest` | 注册 | `username: str`, `password: str`, `phone: str\|None`, `sms_code: str\|None`, `email: EmailStr\|None`, `role: UserRole` |
| `LoginRequest` | 登录 | `username_or_email: str`, `password: str` |
| `TokenResponse` | Token | `access_token: str`, `token_type: str` |
| `CurrentUserResponse` | 当前用户 | `id`, `username`, `phone`, `wechat_openid`, `email`, `role`, `status`, `created_at`, `updated_at` |
| `ChangePasswordRequest` | 改密码 | `old_password: str`, `new_password: str` |

**审计与导入**

| Schema 类 | 用途 | 关键字段 |
|-----------|------|----------|
| `AuditLog`（前端 type） | 审计日志 | `id`, `user_id`, `action`, `resource_type`, `resource_id`, `details`, `ip_address`, `created_at` |
| `ImportTask`（前端 type） | 导入任务 | `id`, `admin_id`, `source_name`, `source_type`, `status`, `total_records`, `success_records`, `failed_records`, `created_at` |
| `ImportTaskDetail`（前端 type） | 导入详情 | 继承 ImportTask + `error_log`, `updated_at` |
| `ImportPreview`（前端 type） | 导入预览 | `task_id`, `file_name`, `column_mapping`, `headers`, `preview_rows`, `total_rows`, `valid_rows`, `incomplete_rows`, `outlier_rows`, `outlier_warnings`, `missing_required` |
| `ColumnMapping`（前端 type） | 列映射 | `matched: Record<str,str>`, `unmatched: string[]`, `confidence: Record<str,str>` |
| `AdminStats`（前端 type） | 运营统计 | `total_users`, `total_properties`, `total_bookings`, `pending_bookings`, `properties_by_district` |

**通知管理**

| Schema 类 | 用途 | 关键字段 |
|-----------|------|----------|
| `NotificationRead` | 通知响应 | `id`, `user_id`, `type: NotificationType`, `title`, `content`, `body`, `entity_type`, `entity_id`, `order_id`, `agreement_id`, `property_id`, `is_read`, `created_at` |
| `UnreadCount` | 未读数 | `count: int` |
| `NotificationListResponse` | 通知列表 | `items: list[NotificationRead]`, `total`, `page`, `page_size` |

## 5. 涉及的数据表

> 完整字段定义见 `01_数据库设计.md` 3.4 节及跨模块引用。

| 表 | 用途 | 核心 FK 关联 |
|----|------|-------------|
| `users` | 用户管理（CRUD + 角色变更） | —（自引用 via created_by） |
| `audit_logs` | 审计日志（append-only，按 action/resource_type 查询） | →users SET NULL |
| `data_imports` | 批量导入任务（csv/excel/api 三种来源） | →users (admin_id) |

> **注意**：`import_jobs` 和 `system_configs` 表不存在。实际使用 `data_imports`；系统配置通过 `config.py` + `.env` 管理。

## 6. 异常处理

| 场景 | HTTP 状态码 | 用户提示 |
|------|------------|----------|
| 导入文件格式错误 | 400 | "文件格式不正确，请使用模板" |
| 导入数据校验失败 | 422 | "第 N 行：[字段] 校验失败：[原因]" |
| 导入任务不存在 | 404 | "导入任务已过期或不存在" |
| 修改超级管理员角色 | 403 | "不允许修改超级管理员角色" |
| 批量操作部分失败 | 200 (含 errors 列表) | "X 条成功，Y 条失败，点击下载错误详情" |
