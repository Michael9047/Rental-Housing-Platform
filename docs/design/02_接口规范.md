## 1. 通用约定

### 1.1 基础信息

| 项目 | 值 |
|------|-----|
| API 前缀 | `/api/v1` |
| 协议 | HTTP/1.1 + JSON |
| 编码 | UTF-8 |
| 认证方式 | `Authorization: Bearer <access_token>` |

### 1.2 通用响应格式

**成功响应**：

```json
{
  "id": 123,
  "name": "..."
}
```
或列表：
```json
[
  { "id": 1, "name": "..." },
  { "id": 2, "name": "..." }
]
```

**错误响应**（统一由全局 exception handler 生成）：

```json
{
  "error": {
    "type": "http_error | validation_error | internal_error",
    "message": "人类可读的中文错误描述",
    "details": null
  }
}
```

### 1.3 分页

- 参数：`skip`（偏移量，默认 0）、`limit`（每页条数，默认 20，最大 200）
- 当前不返回 `total` 和分页元数据（后续版本补充）

### 1.4 HTTP 动词约定

| 动词 | 用途 |
|------|------|
| GET | 读取（无副作用） |
| POST | 创建 |
| PATCH | 部分更新 |
| DELETE | 删除（软删除） |

## 2. 认证鉴权

### 2.1 认证端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/auth/register` | 公开 | 手机号注册 |
| POST | `/auth/login` | 公开 | 密码登录 |
| POST | `/auth/phone-login` | 公开 | 短信验证码登录 |
| POST | `/auth/send-sms-code` | 公开 | 发送验证码 |
| POST | `/auth/verify-sms-code` | 公开 | 校验验证码 |
| POST | `/auth/refresh` | Bearer refresh_token | 刷新 access_token |
| GET | `/auth/me` | Bearer access_token | 获取当前用户信息 |
| GET | `/auth/wechat/qr` | 公开 | 微信扫码登录二维码 |
| POST | `/auth/wechat/callback` | 公开 | 微信登录回调 |

### 2.2 角色权限矩阵

| 角色 | 常量 | 权限范围 |
|------|------|----------|
| 租客 | `tenant` | 搜索、预约、支付、查看自己的订单和合同 |
| 楼栋管理员 | `bm` | 管理自己负责的楼栋/户型/图片/员工 |
| 系统管理员 | `admin` | 全部权限，含用户管理、数据导入导出 |
| 维修工人 | `maintenance` | 查看/更新分配给自己的维修工单 |

### 2.3 依赖注入

```python
# backend/app/api/deps.py
get_current_user       → 解析 JWT，返回 User
require_tenant         → get_current_user + role == "tenant"
require_landlord       → get_current_user + role == "bm"
require_admin          → get_current_user + role == "admin"
require_maintenance    → get_current_user + role == "maintenance"
```

## 7. 错误码规划（后续版本）

> 当前使用 HTTP 状态码 + English error type，后续版本规划统一业务错误码，便于前端 i18n。

```
ERR_AUTH_001  — 用户名或密码错误
ERR_AUTH_002  — 验证码过期
ERR_BOOK_001  — 房源不可订
ERR_BOOK_002  — 入住日期冲突
ERR_PAY_001   — 支付渠道不可用
ERR_PAY_002   — 支付金额不匹配
...
```
