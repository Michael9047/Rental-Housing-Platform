# 右侧 Agent 房源卡片与交互综合测试报告

- 测试日期：2026-08-05
- 测试对象：普通搜索页右侧 Agent、房源推荐卡片、房源对比、筛选记忆与异常输入
- 结论：本轮目标已完成；右侧卡片更大、更清楚，房源名称去重生效，对比入口可见且支持明确勾选，主要用户问法和边界问法均已建立回归测试。

## 一、本轮改动

### 1. 右侧 Agent 卡片

- 桌面端右侧区域由原来的约 390px 放大为 480px；较小桌面断点为 440px。
- 推荐卡片放大为 406px 宽、至少 150px 高。
- 图片区为 154×150px，文字区约 250×150px。
- 放大房源标题、租金、匹配说明和输入区字号。
- 卡片新增户型、卫浴、面积，关键信息无需进入详情页即可查看。
- 移除消息区原有高度上限，使卡片和长对话可使用完整可用高度。
- 修正对比复选框的嵌套标签结构，避免横向卡片中的焦点或点击歧义。

### 2. 房源对比

原有对比能力确认存在：

- 右侧 Agent 顶部有“对比找房”，会比较当前搜索结果。
- 独立 AI 找房页已有勾选对比。

本轮新增：

- 每张右侧推荐卡都有“对比”复选框。
- 可勾选 2–5 套，点击“对比已选房源”。
- 后端只比较明确传入的房源 ID，不混入其他候选。
- 少于两套时返回“请至少选择 2 套有效房源进行对比”。
- 保留原有“比较当前结果”入口，用户既可快速全量比较，也可精确比较所选房源。

### 3. 房源名称去重

- 按 `property_id` 去重。
- 再按去空格、忽略大小写后的规范化标题去重。
- 去重规则已接入普通搜索、独立 AI 找房、右侧 Agent 和历史消息回放。
- 演示房源写库前增加名称唯一性校验。
- 演示目录扩充为 6 个市场、20 个房型、40 间房。

### 4. 扩展自然语言理解

实际浏览器扩展测试发现并修复了三类问法：

- “预算至少 2100 新币”或“2100 新币以上”会识别为最低预算，而不是最高预算。
- “只看 Queenstown/Westwood 区域”会识别英文区域名。
- 从“新加坡/NUS”明确切换到“美国”时，会清除旧学校和旧区域，避免跨市场条件冲突。
- 以上确定性规则在大模型不可用时生效；大模型可用但漏字段时也会再次补齐。

## 六、已知限制

1. `npm run build` 的 `vue-tsc` 仍被项目中已有的预订模块和其他模块类型问题阻塞，例如缺少 `vitest`、`@vue/test-utils`、`@/services/policy`、若干 booking store/type 文件，以及旧 Property 类型字段不完整。Vite 实际生产打包已成功；本轮 Agent 文件没有新增类型错误。
2. 浏览器验收关闭了外部大模型密钥，主要验证可复现的确定性降级路径；同时已用模拟“大模型漏字段”的自动化用例验证最低预算、英文区域和租期规则仍会补齐。
3. 自然语言不可能穷举所有句式。本次按问题类别覆盖：宽泛、精确、连续修改、设施累积、指代、全量对比、明确勾选对比、对比不足、未知地点、跨市场、FAQ、无关问题、空输入和长度边界。

## 七、验收建议

开发数据库启动后，可执行演示数据脚本写入 6 个市场的完整目录，再用真实图片、POI、评价和外部大模型各做一轮预发布环境验收。重点复核图片加载、真实通勤数据和长对比回复的滚动体验。
