📐 安全评分算法

SafetyScore = (C × 0.35) + (E × 0.20) + (P × 0.15) +
    (L × 0.10) + (N × 0.10) + (D × 0.10)

其中各因子 (0-100):
  C = 犯罪率倒数指数
  E = 经济水平指数
  P = 警力部署密度
  L = 街道照明与基础设施
  N = 夜间安全指数
  D = 社区凝聚力
